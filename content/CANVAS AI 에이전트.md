**CANVAS AI 에이전트**는 CANVAS 백엔드의 chatbot-api가 서빙하는 LLM 에이전트 묶음으로, jms19가 2026년 10월 23일부터 11월 3일 사이 커밋으로 학습 코드·자동 모델·워크스페이스 편집 에이전트를 만들고 전반을 개편했다.[^1] jms19는 [[Son Jimin]]의 회사 계정이다.[^2] 백엔드 전체 작업은 [[CANVAS 백엔드 개발]] 참고.

## 개요

chatbot-api는 가이드 챗봇과 워크스페이스 생성·편집·자동 모델 에이전트, 커스텀 프로세싱 코드 에이전트, 차트 설정 에이전트, AI Studio 학습 코드 에이전트를 서빙하고, 계정별·에이전트별 대화 세션을 둔다.[^1] LLM은 한 곳(`llm.py`)에서 고르며 OpenAI 모델 또는 자체 vLLM(OpenAI 호환)을 쓸 수 있고, 학습 코드 에이전트만 따로 고를 수 있다.[^1] 챗봇 API, 커스텀 프로세싱 에이전트, 워크스페이스 생성 에이전트 같은 기반은 2026년 2월~8월에 다른 팀원들이 만들었다.[^1]

## 학습 코드 에이전트 (2026-10-23)

GitHub 저장소를 주면 CANVAS AI Studio 형식의 학습 코드를 만들고, 실제로 돌려 보고, 오류를 보고 고치는 루프다.[^1] 이 커밋은 27개 파일, 4,292줄 추가 규모다.[^1]

- 저장소 분석: 저장소를 얕게 받아 코드는 실행하지 않고 AST로 README·파일 트리·모델/Dataset 시그니처·학습 루프·의존성을 요약해 컨텍스트 32k 안에 넣는다.[^1]
- 모델 어댑터: 입출력 실측 결과로 `model.py`를 규칙대로 만들고, LLM은 import·생성식·입력 범위만 고르게 해 로짓 변환·채널·크기 맞춤처럼 저장소마다 반복되던 실수를 코드로 정했다.[^1]
- 경험 메모리: 시험 실행이 실패했다가 수정으로 통과하면 그 규칙을 작업 종류별로 저장해 다음 프롬프트에 넣는다.[^1]
- 분류·MIL 작업용 기준 템플릿(dataset·loss·metric·model·training)을 두었다.[^1]
- 메인 서버와 유저 컨테이너에 시험 학습, 모델 생성·순전파 확인, 사전학습 가중치 받기 경로를 만들어 에이전트가 만든 코드를 사용자 환경에서 돌려 본다.[^1]
- 근거가 있는 패키지(알려진 목록, 저장소의 의존성 선언)만 자동 설치하고 torch 등은 고정한다.[^1]

## 자동 모델 에이전트·저장소 검색 (2026-10-27)

- 자동 모델 에이전트는 챗봇에 하고 싶은 일을 한 번 말하면 저장소 탐색 → AI Studio 모델 생성 → 학습 코드 → 워크스페이스까지 메인 서버 API를 요청자 토큰으로 대신 부른다.[^1]
- 저장소 검색은 목적에서 대상·모델을 뽑고, 사전학습 가중치가 있다고 조사된 저장소 카탈로그 안에서 LLM이 순위를 정한다(GitHub 검색은 쓰지 않고 후보는 최대 6개).[^1]
- 같은 커밋에서 Custom → Custom 연결 실패 수정, Custom Processing 단계별 진행률과 사용자 코드의 `report_progress` 중계, 모델이 선언한 학습 배율(`train_mpp`)로 리샘플하는 추론을 넣었다.[^1]

## 에이전트 전반 개편 (2026-10-29)

이 커밋은 40개 파일, 4,586줄 추가·795줄 삭제 규모다.[^1]

- LLM 어댑터로 모델 전환을 한곳에 모았고, async 경로의 동기 LLM 호출을 스레드로 분리해 이벤트 루프 막힘을 없앴다.[^1]
- 노드 입출력 규약: 노드별 입력·출력 형식을 플래너·코드 엔진·가이드에 공통으로 주입한다.[^1]
- 상류 맥락 주입: 커스텀 코드를 만들 때 앞 노드가 무엇을 내보내는지 함께 넘긴다.[^1]
- 사전학습 가중치 카탈로그(병리 분할·검출 가중치 250행)와 생성 도구를 만들었다.[^1]
- 워크스페이스 생성 때 사용자의 AI Studio 모델 중 알려진 계열만 AI Connector 후보로 플래너에 알린다.[^1]
- 분석 레시피: IEL·TLS 같은 분석의 정의와 검증된 참고 구현을 커스텀 코드 에이전트에 붙여, 같은 요청에 숫자가 달라지지 않게 했다.[^1]
- 차트 에디터 계산: "계산해서 표로" 요청에 LLM이 낸 pandas 코드를 격리된 하위 프로세스에서 돌려 결과 표(CSV)를 돌려준다.[^1]
- 커스텀 코드 edit 모드(기존 코드 수정)를 넣고 워크스페이스 에이전트·그래프 빌더를 보강했으며, 차트·커스텀 코드·그래프 빌더·사용자 모델 시험을 더했다.[^1]

## 가중치 카탈로그 검증 (2026-11-03)

- 카탈로그의 가중치 주소를 미리 받아 검증하고 그 결과를 저장해, 에이전트가 검증된 가중치만 고르게 했다.[^1]
- 검증된 가중치는 인터넷 대신 공유 저장소에서 사용자 폴더로 복사하고, 주소 표기 차이를 정규화했다.[^1]
- 사용자가 DataHub에 직접 넣은 사전학습 가중치의 목록·검증 결과 API를 만들었다.[^1]

## 워크스페이스 편집 에이전트 (2026-11-03)

- 대화로 지금 보고 있는 워크스페이스 그래프를 읽고 고치는 에이전트를 만들었다(편집 처리부 1,136줄 추가).[^1]
- 에이전트가 만들거나 고친 노드를 자동 배치하는 그래프 레이아웃을 넣었다.[^1]
- 메인 서버에 요청자가 열어 둔 워크스페이스 조회 API와 그래프 스냅샷 API를 만들고, WebSocket 접속 관리자가 접속자를 함께 기록하게 했다.[^1]
- 워크스페이스 편집기 시험(338줄)과 그래프 레이아웃 시험을 더했다.[^1]

## 그 밖의 변경

- 2026-11-10 인증 개편 중 chatbot-api도 refresh 토큰으로는 API를 부를 수 없게 했다.[^1]
- 2026-11-18 배포 설정에서 chatbot-api HTTPS를 인증서 환경 변수로 켜게 하고 transformers 버전을 고정했다.[^1]
