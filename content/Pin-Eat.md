**Pin-Eat**은 [[Son Jimin]]의 저장소로, 친구들과 맛집을 지도에 저장하고 공유·추천받는 소셜 Flutter 앱이다.[^1]

## 개요

README는 Pin Eat을 맛집 공유 및 추천 소셜 앱으로 소개한다.[^1] 친구들과 맛집을 공유하고 추천받는 소셜 플랫폼으로, 지도 기반으로 맛집을 저장하고 그룹을 만들어 친구들과 공유할 수 있다고 적혀 있다.[^1] 라이선스 항목에는 개인 프로젝트로 적혀 있다.[^1]

## 주요 기능

- 지도 기반 맛집 저장: 네이버 지도로 맛집 위치를 저장한다.[^1]
- 친구 시스템과 그룹: 친구를 추가해 맛집을 공유하고, 그룹을 만들어 특정 친구들과만 공유한다.[^1]
- 추천 시스템: 같은 위치의 맛집을 저장한 친구를 확인한다.[^1]
- 푸시 알림(친구 요청, 맛집 추천), 맛집 사진 업로드, 가고 싶은 맛집을 따로 관리하는 위시리스트.[^1]

## 개발 기록

저장소는 2025-10-19에 만들어졌다.[^1] 수집 원본은 본인 커밋 중 최근 200건만 담고 있으며, 그중 가장 이른 것은 2025-10-23이다.[^1]

2025년 10월 말에는 지도 화면의 마커 관리, 친구 맛집 하단 시트, 네이버 지역 검색 API를 쓴 검색, 프로필 사진 업로드, 친구 점수 정렬을 만들었고, 앱 이름을 'Pin Eat'으로 바꾸며 스플래시 화면과 알림 화면, Firebase Cloud Functions·FCM 서비스를 넣었다.[^1] 11월 초에는 Kakao API 장소 검색, 하단 시트와 키보드 처리 개선, 이메일·Google 가입, FCM 푸시 알림, 딥링크와 프로필 공유, 계정 삭제, 릴리스 서명 설정을 커밋했다.[^1] 11월 중순에는 iOS Google 로그인과 APNS 토큰 처리, Apple 로그인과 그 디버깅, 비밀번호 찾기, 네이버 지도 API 검색, Firebase Analytics를 다뤘다.[^1] 11월 말에는 Remote Config 버전 확인, EXIF 위치 추출과 이미지 합성, 사진 자르기, VWorld API 건물 폴리곤, 공유 화면(Share Studio), 튜토리얼 화면을 만들었다.[^1]

2025년 12월에는 위시리스트와 위시리스트 초대, PinIt 전환, 검색 디바운스, 여러 화면의 분석 추적, 성별·생년월일 선택 입력으로 바꾼 가입 흐름, 알림 화면, 그룹 상세·관리와 그룹 친구 초대를 커밋했다.[^1] 2026년 1월에는 저장한 맛집의 그룹 필터와 그룹 공유 설정 화면, 사용자 맛집 캐시 동기화를 넣었고, 2026-01-27에 민감한 파일 관리 지침과 보안 체크리스트를 더하며 실제 Firebase 설정을 저장소에서 뺀 것이 마지막 본인 커밋이다.[^1] 이 기간 커밋 메시지에는 앱 버전이 1.0.2에서 1.0.11까지 올라간 기록이 있다.[^1]

## 기술

저장소 언어 비율은 Dart 81.9%, HTML 11.3%, C++ 1.8%, TypeScript 1.6% 순이다.[^1] README에 적힌 기술 스택은 프런트엔드 Flutter 3.x, Provider 상태 관리, Firebase(Auth·Firestore·Storage·Cloud Messaging), Naver Map SDK이고, 백엔드 Firebase Cloud Functions(Node.js/TypeScript), Firestore, Firebase Storage이다.[^1]

[^1]: 원본 비공개
