**studio**는 [[Son Jimin]]이 만든, 생성한 외국어 소설로 어휘와 문법을 익히는 Ñovel 웹 앱이다.[^1]

## 개요

README는 이 저장소를 Firebase Studio의 NextJS 스타터로 소개한다.[^1] 2025-08-04 커밋에서 앱 제목을 Ñovel로 바꿨다.[^1] 커밋 메시지는 대부분 앱에 바라는 변경을 한국어 요청 문장으로 적은 것이다.[^1]

## 주요 기능

커밋 메시지에 나타난 기능은 다음과 같다.[^1]

- 소설 생성: 소설 전체를 한 번에 만든 뒤 문단별로 넘겨 읽고, 주제는 한국어로도 쓸 수 있다.[^1]
- 문장 분석: 문장의 어휘·문법을 설명하고 문장 뜻을 번역하며, 어휘는 원형으로 바꿔 뜻을 보여 준다.[^1]
- 단어장: 단어 추가·삭제·전체 삭제, 남성형·여성형 표시, 스피커 버튼으로 소리 듣기를 지원한다.[^1]
- 여러 언어: 스페인어뿐 아니라 고른 언어로 소설을 만든다.[^1]
- 음성(TTS) 변환 기능이 있다.[^1]

## 개발 기록

2025-08-04에 첫 프로토타입을 커밋하고, 같은 날 문장 분석에 번역을 붙이고 단어장 하이라이트·전치사 추가와 앱 이름 변경을 했다.[^1] 2025-08-05에는 이야기 저장·삭제 확인, 문단별 페이지 넘김, 단어 원형 저장, 호버·길게 누르기 동작, 스페인을 떠올리게 하는 배경, 3인칭 시점 유지 등 화면과 소설 생성 방식을 여러 번 고쳤고, TTS 오류도 고쳤다.[^1] 2025-08-10에는 다른 언어 선택 기능을 넣고 어휘·문법 설명을 한국어로 바꿨으며, 2025-08-11에는 단어장 단어의 소리 듣기를 추가했다.[^1] 마지막 커밋인 2025-08-12에는 뜻 설명 길이와 소설 첫머리 표현을 다듬었다.[^1] 본인 커밋은 모두 77건이다.[^1]

## 기술

저장소 언어는 TypeScript가 97.7%이다.[^1] 의존성에는 Next.js, React, Firebase, Genkit(Google AI 플러그인 포함), Radix UI, Tailwind CSS, Zod가 있다.[^1]

[^1]: 원본 비공개
